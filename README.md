## 📖 Overview
Finding a turf is easy; finding a reliable, balanced game is hard. **[Project Name]** is a web-first sports matchmaking platform designed to fix the broken pick-up game experience. Moving beyond simple venue directories like Playo or Hudle, we combine algorithmic skill pairing, strict anti-ghosting mechanics, and hyper-local social features to build an active community of athletes.

This repository contains the **Minimum Viable Product (MVP)** web application, laying the foundation for our upcoming iOS and Android releases.

---

## 🎯 Problem vs. Solution

| The Problem in Pick-Up Sports | Our Solution |
| :--- | :--- |
| **Skill Mismatch:** Beginners get crushed, and pros get bored in unbalanced lobbies. | **Elo Rating System:** A Chess.com-inspired dynamic rating system that pairs players of similar skill levels. |
| **Last-Minute Ghosting:** Players bail an hour before the game, ruining the match for everyone. | **Flake Penalties:** Backing out last-minute or no-showing directly penalizes a player's Elo and Reliability Score. |
| **Trust & Safety Issues:** Hesitation to visit unfamiliar venues with complete strangers. | **Verified Venue Proof:** Real turf photos, verified turf partnerships, and a live counter of matches previously hosted at each location. |
| **Zero Community:** You play once and never talk to those players again. | **Social Discovery & Local Clans:** Swipe-based player matching, sports-focused profiles, and neighborhood-based Clans. |

## ✨ Key Features

### 🚀 Phase 1: Web MVP Scope (Current)
- **Elo-Based Matchmaking Engine:** Create or join matches filtered by skill bracket. Post-match win/loss and peer evaluations dynamically update player ratings.
- **Anti-Ghosting & Reliability System:** Automated attendance tracking that rewards consistent players and penalizes last-minute dropouts.
- **Verified Turf Directory:** Browse partnered turfs with verified photos, amenities, pricing, and historical match counts to build instant trust.
- **Swipe-to-Match Discovery:** A Tinder-style matchmaking queue to quickly find players looking for a game or teams needing an extra substitute in your area.

### 🗺️ Phase 2: Post-MVP & Mobile Roadmap
- **Locality Clans ("Identity as Unity"):** Join area-specific clans (e.g., South Delhi Strikers, Indiranagar United) to compete on local leaderboards and turf wars.
- **Sports Social Feed:** An Instagram-style feed for match highlights, stat flexing, and local tournament announcements.
- **Native Mobile Apps:** Full transition to iOS and Android (React Native / Flutter) with push notifications for instant match invites.
